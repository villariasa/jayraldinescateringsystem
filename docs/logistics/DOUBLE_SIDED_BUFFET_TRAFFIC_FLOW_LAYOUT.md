# Double-Sided Buffet Line Traffic Flow Architecture & Layout

> **Target Version:** v4.2.5  
> **Status:** Spatial Planning Guide  
> **Date:** October 8, 2026  
> **Audience:** Banquet Captains, Event Designers, Venue Setup Crew

---

## 1. Spatial Clearance & Sizing Requirements
When guest count exceeds **80 pax**, single-sided buffet lines generate excessive queuing delays. Double-sided mirrored service is mandatory.

```
       [ Plating Station: Dual Stacks of 10" Dinner Plates ]
                      ┌──────────────────────┐
    Flow A ──────────►│  Dishes 1 to 6 (Row) │──────────► Cutlery / Napkins
                      ├──────────────────────┤
    Flow B ──────────►│  Dishes 1 to 6 (Row) │──────────► Cutlery / Napkins
                      └──────────────────────┘
                  [ 1.5m Minimum Aisle Clearance ]
```

## 2. Station Sequencing Rules
1. **Starches First:** Rice (Plain / Garlic) placed at the start of the line to establish bulk base.
2. **Proteins Centered:** Main dishes (Pork Humba, Beef Kaldereta, Fish Fillet) in the middle.
3. **Delicate Items Last:** Pancit noodles, buttered vegetables, and delicate garnishes.
4. **Cutlery Placement:** Forks, spoons, and napkins positioned at the very end of the line so guests have free hands while serving.
