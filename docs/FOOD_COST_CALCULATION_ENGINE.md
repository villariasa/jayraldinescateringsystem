# Food Cost Percentage Calculation Engine Specification

## 1. Core Formula
$$\text{Food Cost } \% = \left( \frac{\text{Raw Ingredient Cost}}{\text{Menu Selling Price}} \right) \times 100$$

## 2. Operational Thresholds
- **Target Food Cost**: 30% - 35% of package gross revenue.
- **Prep Wastage Buffer**: Automatic 5% - 8% shrinkage factor added to meat and perishable produce orders.
