# Cebu Province Barangay Address Hierarchy & Geocoding

## 1. Geographic Data Model
Pre-populates hierarchical address structures for rapid kiosk input:

- **Province**: Cebu
- **Major Municipalities**: Cebu City, Mandaue City, Lapu-Lapu City, Talisay City, Consolacion, Liloan, Minglanilla.
- **Auto-Suggestions**: Autocompletes street, subdivision, and barangay coordinates with instant delivery zone calculation.
