# Unified Application Error Codes Taxonomy

## 1. Code Taxonomy
- `ERR_DB_101`: PostgreSQL connection refused. Verify service running on port 5432.
- `ERR_DB_102`: Authentication failed. Check database username and password in DB settings.
- `ERR_NET_201`: Sync server unreachable on port 8000. Verify firewall rules.
- `ERR_AUTH_301`: Invalid Owner PIN / Password entered.
- `ERR_SYNC_401`: Optimistic lock version mismatch during sync ingestion.
