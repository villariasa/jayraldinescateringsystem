# Tablet Kiosk Hardware Deployment & Peripheral Setup Guide

## 1. Hardware Checklist
- Android Tablet (10-inch screen, minimum 4GB RAM, Android 11+).
- Secure locking countertop tablet stand.
- 80mm ESC/POS thermal receipt printer (Bluetooth or Wi-Fi).
- Dedicated 5GHz Wi-Fi access point SSID for catering operations.

## 2. Android Kiosk Mode Configuration
Pin the Jayraldine's Catering APK as the device owner or lock navigation bars using Android Screen Pinning to prevent unauthorized app exits by guests.
