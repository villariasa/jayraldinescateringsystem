# Dark Theme Contrast Ratio Compliance for OLED Tablet Screens

## WCAG 2.1 AA Compliance:
- Background: `#0B1220` (slate black).
- Primary Text: `#F8FAFC` (contrast ratio 15.2:1 against background).
- Secondary Text: `#94A3B8` (contrast ratio 5.1:1 against background).
- Accent Gold: `#D97706` (contrast ratio 4.8:1 against card surface).
