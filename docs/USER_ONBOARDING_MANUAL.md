# Staff Quick-Start Onboarding Manual

## 1. Welcome to Jayraldine's Catering System
This manual trains front-of-house staff, cashiers, and banquet coordinators on standard daily workflows.

## 2. Step-by-Step Workflows
1. **Logging In**: Enter employee PIN on login screen.
2. **Taking a Booking**: Navigate to Bookings -> New Event -> Select Client -> Choose Package -> Set Date & Venue.
3. **Recording Payments**: Open Billing -> Enter Amount Paid -> Select Payment Method -> Print Official Receipt.
