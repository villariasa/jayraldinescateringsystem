# System Environment Variables & Configuration Reference

## 1. Environment Variable Reference
- `DB_HOST`: Host address of the PostgreSQL database (default: `localhost`).
- `DB_PORT`: Port number of the PostgreSQL database (default: `5432`).
- `DB_NAME`: Database catalog name (default: `jayraldines_catering`).
- `DB_USER`: Database authentication username (default: `postgres`).
- `DB_PASSWORD`: Database authentication password.
- `SYNC_PORT`: Port for the background sync daemon HTTP server (default: `8000`).
