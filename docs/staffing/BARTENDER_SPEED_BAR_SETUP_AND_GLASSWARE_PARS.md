# Mobile Bartender Speed Bar Setup & Glassware Par Stock Ratios

> **Target Version:** v4.2.5  
> **Status:** Beverage Service SOP  
> **Date:** October 8, 2026  
> **Audience:** Head Bartender, Banquet Logistics

---

## 1. The Speed Rail Ergonomic Layout
Mobile banquet bars require tight spatial efficiency:

```
[ Ice Chest (Center) ]
  ├── Left Rail: Simple syrup, Calamansi juice, Grenadine, House mixers
  ├── Right Rail: House spirits, Ice scoop (in sanitized dry holder)
  └── Bar Top: Spill mat, garnish caddy (lime wheels, cherries), straw/napkin caddy
```

## 2. Glassware Par Inventory per 100 Guests

| Glassware Type | Target Par Level | Turnover Factor |
|---|---|---|
| All-Purpose Goblet (Water/Iced Tea) | 150 pcs (1.5x) | Continuous washing / bussing |
| Highball Glass (Cocktails/Juice) | 130 pcs (1.3x) | Return to wash station |
| Champagne Flute (Toast Service) | 110 pcs (1.1x) | Single-use toast cycle |
| Wine Glasses (Red / White) | 120 pcs (1.2x) | Dedicated table placements |
