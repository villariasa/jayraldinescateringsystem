# Catering Crew to Guest Headcount Staffing Ratios

> **Target Version:** v4.2.5  
> **Status:** Staffing Standards  
> **Date:** October 8, 2026  
> **Audience:** HR, Banquet Coordinators, Event Quoters

---

## 1. Standard Service Ratios by Event Type

| Service Format | Waitstaff Ratio | Busser Ratio | Banquet Captain Allocation |
|---|---|---|---|
| Standard Buffet (Self-Service) | 1 server per 25–30 guests | 1 busser per 40 guests | 1 captain per 100 guests |
| Assisted Buffet (Staff Plating) | 1 server per 15–20 guests | 1 busser per 35 guests | 1 captain per 80 guests |
| Sit-Down Plated Dinner | 1 server per 10–12 guests | 1 busser per 25 guests | 1 captain per 50 guests |
| Cocktail / Heavy Hors d'oeuvres | 1 server per 20 guests | 1 runner per 50 guests | 1 captain per 100 guests |

## 2. Additional Specialized Staff Roles
- **Carving Station Chef:** Dedicated 1 per 100 guests requiring carved roast meats (Lechon Belly, Roast Beef).
- **Beverage Station Attendant:** 1 per 75 guests for bar setups with specialty mocktails.
- **Dish Stewards (On-Site Warewashing):** 2 per 150 guests if venue provides dishwashing facilities.
