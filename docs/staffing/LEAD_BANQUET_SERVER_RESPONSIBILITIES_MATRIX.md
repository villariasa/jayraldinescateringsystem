## 1. Station Responsibilities
- **VIP Table Lead:** Dedicated server assigned exclusively to Presidential / Bridal tables; manages prompt beverage refills and individualized plated course delivery.
- **Buffet Line Monitor:** Oversees guest plate flow, soup ladle cleanliness, and communicates replacement pan requests to kitchen runners.
- **Floor Busser Lead:** Coordinates quick table clearing, crumb sweeping between courses, and water pitcher replenishment.
