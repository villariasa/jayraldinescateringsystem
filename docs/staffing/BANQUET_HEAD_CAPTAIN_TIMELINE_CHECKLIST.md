# Banquet Head Captain Event Timeline Checklist

## Captain Milestones
- T-3 Hours: Venue ingress, table layout verification, staff briefing.
- T-1 Hour: Buffet line setup, warmer lighting, beverage station readiness.
- T-0: Guest ingress, welcome drinks, coordinate program timeline with host.
- T+3 Hours: Pack-up, inventory count, venue manager walkthrough sign-off.
