# Dark & Light Mode Design System Specification

## 1. Design Tokens
- **Dark Mode**: Deep slate background (`#121824`), elevated card surfaces (`#1A2234`), high-contrast text (`#F8FAFC`).
- **Light Mode**: Crisp white surfaces (`#FFFFFF`), subtle borders (`#E2E8F0`), deep slate typography (`#0F172A`).
- **Accent Color Engine**: Dynamically re-binds CSS variables (`--primary-accent`) across all views.
