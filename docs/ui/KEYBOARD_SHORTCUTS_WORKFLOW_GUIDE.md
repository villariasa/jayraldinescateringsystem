# Cashier Desktop Keyboard Accelerators Guide

## 1. Registered Shortcuts
- `Ctrl + N`: New Catering Booking.
- `Ctrl + F`: Global Customer / Booking Search.
- `Ctrl + P`: Print Active Invoice / Receipt.
- `Ctrl + D`: Switch to Dashboard View.
- `F5`: Refresh Active Data View.
- `Esc`: Dismiss Active Dialog / Cancel Input.
