# Vector PDF Rasterization Pipeline for High-DPI Displays

## 1. DPI Scaling Matrix
On Windows 10/11 multi-monitor environments with 125%, 150%, or 200% display scaling:
$$\text{Effective DPI} = 96 \times \text{DevicePixelRatio}$$
Preview canvases render at 300 DPI baseline to prevent blurry text when inspecting catering contracts.
