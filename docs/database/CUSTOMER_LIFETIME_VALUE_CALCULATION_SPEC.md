# Customer Lifetime Value (CLV) Calculation Specification

## 1. Formula
$$\text{CLV} = \sum_{i=1}^{N} \text{Settled Invoice Amounts} - \sum_{i=1}^{N} \text{Specific Discounts Approved}$$

## 2. Customer Tiering
- **Platinum Tier**: $\text{CLV} > \text{₱250,000}$ (Eligible for complimentary appetizer bar upgrades).
- **Gold Tier**: $\text{₱100,000} - \text{₱250,000}$.
- **Silver Tier**: $< \text{₱100,000}$.
