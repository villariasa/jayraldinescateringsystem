# Commercial Warewashing Sanitation & Temperature Standards

## 1. Warewashing Thermal Standards
- **Wash Cycle**: $65^{\circ}\text{C} - 71^{\circ}\text{C}$ ($150^{\circ}\text{F} - 160^{\circ}\text{F}$) with commercial alkaline detergent.
- **Sanitizing Rinse Cycle**: Minimum $82^{\circ}\text{C}$ ($180^{\circ}\text{F}$) high-temperature thermal rinse guaranteeing complete pathogen eradication.
