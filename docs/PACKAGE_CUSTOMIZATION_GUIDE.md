# Dynamic Catering Package Builder & Customization Guide

## 1. Overview
The package customization engine enables front-desk staff to personalize buffet packages according to client preferences while dynamically recalculating total per-head pricing.

## 2. Customization Mechanics
- **Category Quotas**: Enforces selection limits (e.g., 2 Beef/Pork viands, 1 Chicken viand, 1 Pasta/Noodle, 1 Dessert, 1 Drink).
- **Dish Upgrade Fees**: Swapping standard items with premium dishes (e.g., Roast Beef or Salmon) automatically applies incremental surcharges per guest.
- **Live Recalculation**: Subtotals and contract grand totals update in real-time as items are toggled.
