# Official Release Notes — Version 4.2.1

## Release Summary
Version 4.2.1 brings standalone Android tablet APK distribution over local Wi-Fi, intelligent in-app download suppression, sticky category navigation with dynamic dish counters, and the live menu showcase module.

## Highlights
- **Direct LAN APK Distribution**: Install the Android tablet app directly from the PC server via `http://<server-ip>:8000/download-apk`.
- **In-App Prompt Suppression**: Download buttons automatically hide when running inside the installed APK app.
- **Sticky Category Filter**: Step 3 search and category pills stay visible while scrolling through dishes.
- **Live Menu Showcase**: Guests can preview dishes and pricing directly on the kiosk landing page.
