# GCash & Maya Digital Wallet Dynamic QR Code Generation Specification

## 1. Dynamic QR Generation
The billing module renders standard EMVCo-compliant QR codes:
- Encodes merchant account ID, transaction reference, and exact billing amount.
- Enables instant mobile scanning by clients using the GCash or Maya smartphone apps.

## 2. Payment Confirmation
Cashiers input the 8-digit digital wallet transaction reference number before printing the official receipt.
