# Data Export Schemas & Formatting Specification

## 1. Supported Export Types
- **Microsoft Excel (.xlsx)**: Formatted financial reports, customer directories, and inventory audits with styling and formulas.
- **Comma Separated Values (.csv)**: Raw transactional data for accounting software import.
- **Structured JSON (.json)**: Full system data backup and REST API interoperability format.

## 2. Compliance
All exports enforce ISO 8601 date formatting (`YYYY-MM-DDTHH:MM:SS`) and Philippine Peso currency encoding (`PHP` / `₱`).
