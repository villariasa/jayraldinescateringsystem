# Disaster Recovery Simulation Protocol & Offsite Archival

## 1. Exercise Schedule
Disaster recovery simulation drills are scheduled semi-annually to validate data restoration times.

## 2. Recovery Steps
1. Simulate catastrophic hardware destruction by provisioning a fresh workstation.
2. Install Jayraldine's Catering System via the Inno Setup installer.
3. Restore the latest daily SQL backup archive.
4. Execute checksum validation scripts to verify 100% record parity.
