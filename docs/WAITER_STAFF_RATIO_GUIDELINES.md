# Banquet Staffing Ratios & Service Standard Guidelines

## 1. Standard Staffing Multipliers
- **Buffet Service**: 1 Banquet Server per 25-30 guests.
- **Plated VIP Service**: 1 Banquet Server per 12-15 guests.
- **Beverage Station**: 1 Dedicated Bar Attendant per 100 guests.
- **Carving Station (Lechon de Cebu)**: 1 Master Carver + 1 Runner per station.
- **Banquet Captain**: 1 Lead Captain for events exceeding 80 guests.
