# Predictive Cash Flow Forecasting & Receivables Analysis

## 1. Liquidity Modeling
- **Expected Inflows**: Aggregates upcoming booking final balances scheduled for collection on event dates.
- **Committed Outflows**: Forecasts ingredient procurement expenses based on confirmed event headcount for the next 14 days.
- **Net Liquidity Index**: Calculates real-time working capital availability to ensure smooth commissary operations.
