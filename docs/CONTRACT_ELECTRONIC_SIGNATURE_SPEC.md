# HTML5 Canvas Electronic Signature Capture & PDF Embedding

## 1. Digital Signature Pipeline
- **Smooth Bezier Drawing**: Captures client fingertip/stylus signature strokes on touchscreens using dynamic Bezier curves.
- **PNG Extraction**: Encodes signature path to high-contrast transparent PNG.
- **Tamper-Proof Binding**: Hashes signature data and embeds directly into ReportLab PDF contract footer.
