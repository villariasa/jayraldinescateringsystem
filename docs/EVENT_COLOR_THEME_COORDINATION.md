# Event Styling Palette Coordination & Linen Mapping

## 1. Theme Presets
Maps customer-selected color themes to physical catering decor:

- **Emerald Elegance**: Deep emerald table skirts, gold charger plates, ivory linen runners.
- **Royal Sapphire**: Navy blue satin overlays, silver candelabras, white damask napkins.
- **Blush Rose Gold**: Dusty rose runners, champagne tablecloths, warm fairy light centerpieces.
- **Rustic Botanical**: Jute burlap accents, wooden slab risers, eucalyptus foliage runners.
