# Event Venue Floor Plan Layout & Buffet Placement Standards

## 1. Layout Architectural Guidelines
- **Buffet Clearance**: Minimum $1.5\text{ meters}$ queueing clearance in front of chafing dish lines.
- **Service Egress**: Dedicated $1.2\text{ meter}$ service lane behind buffet tables for banquet runner restocking.
- **Guest Table Spacing**: $1.8\text{ meters}$ between round guest tables ($60\text{ inch}$ 10-seaters) to ensure smooth chair movement.
