# Bookings & Scheduling Module Guide

## Lifecycle States
1. `PENDING` -> Initial quotation / draft order
2. `CONFIRMED` -> Downpayment received & contract signed
3. `COMPLETED` -> Event delivered and fully settled
4. `CANCELLED` -> Order voided with optional cancellation reason
