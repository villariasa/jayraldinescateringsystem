# CSS Design Tokens & Color Palette Specification

## 1. Color Palette Tokens
- `--bg`: `#0B1220` (Dark Mode) / `#FFFFFF` (Light Mode).
- `--card`: `#131D38` (Dark Mode) / `#F8FAFC` (Light Mode).
- `--accent`: `#E11D48` (Signature Crimson).
- `--gold`: `#F59E0B` (Banquet Gold).
- `--success`: `#10B981` (Emerald Green).

## 2. Typography
Rendered with Google Font "Plus Jakarta Sans" for modern geometric legibility on high-DPI touchscreens.
