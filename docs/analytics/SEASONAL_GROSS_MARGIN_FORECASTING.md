# Seasonal Gross Margin Forecasting Specification

## 1. Economic Variables
- Inflation index on pork and poultry wholesale prices during Q4 holiday rush.
- Package margin equation:
$$\text{Gross Margin} = \frac{\text{Package Price} - (\text{Ingredient Cost} + \text{Labor Par})}{\text{Package Price}} \times 100$$
Target margin threshold: $\ge 42\%$.
