# Dish Popularity Index & Menu Rationalization Algorithm

## 1. Metrics
- **Selection Rate ($S_r$)**: $\frac{\text{Bookings Selecting Dish}}{\text{Total Eligible Bookings}}$
- **Guest Consumption Index ($C_i$)**: Waste audit return percentage from banquet stewarding.
- Dishes with $S_r < 5\%$ over 6 months are flagged for culinary re-engineering or retirement.
