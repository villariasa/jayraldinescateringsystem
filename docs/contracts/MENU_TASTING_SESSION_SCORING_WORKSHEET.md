## 1. Session Setup & Presentation
- Host tasting in the dedicated commissary boardroom setup with formal banquet table settings.
- Present 4 to 6 candidate main dishes in authentic single-portion tasting formats.
- Provide palate cleansers (lemon-infused water, unsalted crackers) between courses.
