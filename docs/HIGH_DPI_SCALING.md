# High-DPI & Display Scaling Guide

## Qt DPI Attributes
- `Qt.AA_EnableHighDpiScaling` enabled by default.
- Relative font sizing (`px` with minimum bounding heights).
- Responsive grid layouts adapting from 1366x768 up to 4K displays.
