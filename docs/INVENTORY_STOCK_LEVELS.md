# Inventory Minimum Stock Thresholds & Reorder Triggers

## 1. Threshold Configuration
Each raw ingredient and commissary item is assigned:
- **Minimum Par Level**: Safety buffer threshold.
- **Reorder Quantity**: Standard procurement batch volume.
- **Unit of Measurement**: Standardized kilograms, liters, cans, or pieces.

## 2. Automatic Reorder Alerts
When confirmed bookings deplete projected stocks below safety thresholds, the inventory module highlights the row in red and generates a suggested Purchase Order requisition list.
