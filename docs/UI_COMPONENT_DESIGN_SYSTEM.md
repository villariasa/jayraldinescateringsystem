# PySide6 UI Component Library & Design System

## 1. Design Principles
- **Clarity & Focus**: High visual contrast between background panels and actionable buttons.
- **Consistent Elevation**: Standard drop-shadow tokens for cards, dialog modals, and dropdown overlays.
- **Responsive Geometry**: Layouts expand fluidly across 1080p, 2K, and 4K displays.

## 2. Component Inventory
- `PrimaryButton`, `SecondaryButton`, `DangerButton`.
- `StatusBadge` (Pending, Confirmed, Completed, Cancelled).
- `CircularSpinner` (60fps indeterminate loading animation).
- `MetricCard` (KPI counter with trend indicators).
