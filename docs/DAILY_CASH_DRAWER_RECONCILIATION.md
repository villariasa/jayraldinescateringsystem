# Daily Cash Drawer Register Reconciliation Guide

## 1. Workflow
1. **Morning Float**: Cashier verifies opening cash float (standard ₱5,000.00).
2. **Shift Transactions**: System logs cash receipts and petty cash disbursements.
3. **End-of-Day Close**: Cashier counts physical currency denominations.
4. **Discrepancy Calculation**: System compares counted cash against expected register balance, generating an Over/Short variance report.
