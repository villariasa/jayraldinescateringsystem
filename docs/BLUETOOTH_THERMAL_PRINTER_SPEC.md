# Bluetooth Thermal Receipt Printer (ESC/POS) Integration Specification

## 1. Printer Specs
- **Print Width**: 80mm (576 dots/line).
- **Interface**: Bluetooth 4.0 / BLE and Wi-Fi.
- **Command Set**: Standard Epson ESC/POS command set.

## 2. Formatting Engine
Generates crisp vector-aligned receipts with company header logo, customer name, package breakdown, amount paid, and QR verification code.
