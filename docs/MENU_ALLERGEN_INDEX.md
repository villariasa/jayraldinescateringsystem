# Culinary Allergen Classification & Dietary Taxonomy

## 1. Standard Allergen Classifications
- **DAIRY**: Milk, butter, cream, cheese.
- **EGG**: Whole eggs, mayonnaise, meringue.
- **SEAFOOD**: Shrimp, crab, squid, fish sauce.
- **PEANUT / TREE NUT**: Cashews, peanuts, almonds.
- **GLUTEN**: Wheat flour, soy sauce, pasta.

## 2. Dietary Preference Tags
- Vegetarian (🌱), Vegan (🌿), Halal-Friendly (حلال), Low-Sodium (🧂), Keto-Friendly (🥩).
