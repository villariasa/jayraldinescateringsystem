# Semantic Versioning & Release Policy

## Format: `vMAJOR.MINOR.PATCH`
- **MAJOR**: Breaking schema alterations or foundational rewrites.
- **MINOR**: New business modules, installer features, and sync updates.
- **PATCH**: Bug fixes, styling refinements, and security patches.
