# Banquet Server Pre-Event Briefing Procedure

> **Target Version:** v4.2.4  
> **Status:** Approved / Active Runbook  
> **Date:** October 7, 2026  
> **Component:** Staff Management, Service Quality, Banquet Coordination

---

## 1. Briefing Timeline (T-minus 45 Minutes to Event)
The Captain Waiter conducts a mandatory 15-minute alignment with all service staff.

---

## 2. Briefing Checklist

1. **Grooming Inspection:**
   - Complete clean uniform, black slacks, polished closed shoes.
   - Hair tied in neat hairnets/buns; clean hands and trimmed fingernails.
2. **Event Details Alignment:**
   - VIP tables and celebrant table positioning.
   - Special dietary requirements (e.g. Table 4: 2 Halal, Table 6: 1 Peanut Allergy).
   - Event timeline: Opening prayer, grand entrance, buffet opening call, toast.
3. **Table Allocation:**
   - Standard ratio: 1 server per 25 guests (3 tables per server).\n
