# Catering Operational Event Checklist Runbook

## 1. Pre-Event (T-24 Hours)
- Print final Banquet Preparation Sheets from Kitchen view.
- Perform device sync check on all tablet kiosks.
- Verify downpayment clearance on billing ledger.

## 2. Event Execution
- Track live pax check-ins and add-on drink orders on tablets.
- Print final balance invoice upon customer departure.
