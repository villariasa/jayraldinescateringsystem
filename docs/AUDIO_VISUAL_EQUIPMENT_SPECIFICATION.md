# Banquet Audio-Visual (AV) Equipment Specifications

## 1. AV Fleet Configuration
- **PA Powered Speakers**: Dual 15" $1000\text{W}$ active powered speakers with tripod stands.
- **Wireless Microphones**: Dual UHF diversity handheld microphones ($600-690\text{MHz}$) with anti-interference frequency scanning.
- **Audio Mixer**: 8-channel compact mixer with Bluetooth input and parametric equalizer.
- **Projection**: 4000 Lumens Full HD projector with $100\text{ inch}$ motorized tripod screen.
