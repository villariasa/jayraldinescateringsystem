# Kitchen Order Ticket (KOT) Routing & Formatting Specification

## 1. Ticket Layout
Every KOT includes:
- **Event Identifier**: Booking reference code and client name.
- **Serving Timestamp**: Ingress, buffet opening, and egress schedule.
- **Guest Headcount**: Total confirmed pax and dietary exception breakdown.
- **Itemized Dish Preparation List**: Batch counts in food warmers/chafing dish pans.

## 2. Station Separation
Tickets are routed to specific kitchen stations: Hot Kitchen (Main Entrees), Cold Pantry (Salads & Appetizers), and Pastry Section (Desserts & Beverages).
