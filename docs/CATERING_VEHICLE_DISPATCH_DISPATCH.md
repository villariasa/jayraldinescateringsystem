# Catering Fleet Dispatch & Vehicle Load Capacity Planning

## 1. Fleet Capacity Matrix

- **Dispatch Scheduling**: Departure scheduled $2.5\text{ hours}$ prior to guest arrival to ensure complete ingress before event opening.
