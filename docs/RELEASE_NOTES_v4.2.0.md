# Official Release Notes — Version 4.2.0

## Release Summary
Version 4.2.0 introduces enterprise-grade multi-terminal local synchronization, dynamic database connection controls, owner authorization barriers, and automated Windows firewall configuration.

## What's New
- **Dynamic DB Connection Dialog**: Effortless server configuration and live test connection validation.
- **Owner Auth Dialog**: Elevated security for mission-critical operations.
- **Windows Firewall Automation**: One-click configuration batch script for port unblocking.
- **Tablet Kiosk Sync Upgrades**: High-performance offline order queueing and multi-subnet discovery.
